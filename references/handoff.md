# 两份 Word 与交付验收

**逐页填充稿。** 每页从“幻灯片第 N 页”和最终页题开始。按实际放映布局收录正文、表格和原图，说明文字与图表分别放在哪里。表格使用 Word 原生表，同一张图出现不同裁切时，插入各页真正展示的面板与图例。复制上屏出处时沿用短标签。论文原图图片中的文字无需重复打成整页截图。

**演讲人汇报稿。** 保留相同的“幻灯片第 N 页”和页题。封面用临床问题开场，章节页写转场；方法页解释设计选择，结果页给听众一条读图路径。说明比较对象、数字代表的单位，以及结论如何通向下一页。给正文页的相应口播重点加深红色，讲者专用的“原文定位”可以保留详细出处。必要时附上有原文依据的现场备答。

## 交付核对

| 检查对象 | 应看到的结果 |
|---|---|
| 页序和内容 | 两份 Word 的幻灯片导航与最终 PPT 连续对应。页题、表格单元格、关键数字、单位和图例一致。Word 物理页数独立于幻灯片数量。 |
| 证据与红字 | 从概览起，每个含正文的页段都能定位红色读数或结论；封面、团队和章节页保持黑字。注意“百分点”与“百分比”、中位随访与验证时点等易混口径。 |
| 放映与打印 | 在实际放映尺寸检查标题、图例、原图、来源及正文边界。在 Word 打印布局检查分页、续表、孤行或图注落单。 |
| 文件交付 | 在独立子文件夹给出 PPT 和两份 Word，注明数据冲突、推断或未能取得的材料。根据用户要求附修改报告或预览。 |

可用 Python 3 对三件套作结构初查。以下参数按顺序为 PPT、逐页填充稿和演讲稿，相对路径以实际运行目录为准。

```text
python scripts/check_report.py report.pptx fill.docx speech.docx
```

该工具检查包能否读取、页导航、讲者备注覆盖情况、表格及图片对象数量，并列出含深红文字的幻灯片。需要人工判断标题是否属于实质内容、结果是否准确及真实放映时有无越界。
