# 幻灯片版式

## 页型与版面

| 页型 | 制作要点 |
|---|---|
| 封面 | 白底黑字，优先采用用户给的参考。长题名可用中文在上、英文在下，按词组换行。期刊、年卷页、DOI、作者和经核实的日期居中排列。若列影响因子，注明其数据年份和来源。 |
| 团队与方向 | 黑色正文。分别说明作者所属团队、与本文有关的研究方向或已核实的前期工作，以及本研究的数据分工。可配论文图形摘要。只有机构和作者姓名时，宁可少写，也不要根据署名推断个人领导关系。 |
| 研究概览 | 用“临床问题、设计与模型、主要发现、延伸应用”四行原生表。最后一行可替换为病例应用、临床意义或其他符合论文的内容。 |
| 方法、结果与讨论 | 一页回答一个问题。人群、终点、时点、分母和读图依据决定适宜的文字量。文字页补设计理由，表格页补比较口径，图页优先放大关键面板并在旁边解释。 |
| 总结及本组设想 | 可用“目的、方法、结果、结论”四行总结。最后的本组设想写清拟纳入谁、用什么结局、在什么时点评价，并标明为汇报者提出。 |

中文用宋体，英文及阿拉伯数字用 Times New Roman。页面顶部的题句居中，段落标签、正文及表内说明沿各自左边界对齐。章节保留“一、研究背景”式编号，内容页不附装饰性序号，需要排序的结果页写“结果1　……”。模板数字仅用作排版示意，实际页码须与放映顺序相符。

## 每页重点与图例

封面、团队页及纯章节页使用黑字。所有页首标题、分段标题、表头、行标签均为黑色。从研究概览开始，每张有正文的幻灯片在正文或表格内用深红色 **#C00000** 标清最值得听众注意的数字、结论或读图依据。连同决定读数含义的单位、方向或必要的区间一起标注；同页其他文字保持原色。

尽量使用原论文图，保留坐标、单位、置信区间、图例和实际纵横比。多面板图先按问题拆分。新加的图例将方块与对应黑字放在同一行，按图的中轴整体居中。可把两组色块和释义做成一个居中段落，以便调整尺寸后仍能保持对齐。

## 页脚只放简注

以论文实际章节名或图表号标注屏幕底部的来源，例如 `Model development 与 External validation`、`Fig. 4`、`S5`。这里省去“来源”前缀、页码、网址和说明文字。封面、纯章节页和仅含本组设想的页面可留空。幻灯片自身的翻页页码独立保留。讲者备注记录印刷页、图表面板、网址、数据差异和原图读法。
